# 教程发布说明

1. 创建 GitHub 仓库，例如 `nextjs-architecture-guide`。
2. 将本目录中的全部文件上传到仓库根目录（不要再套一层文件夹）。
3. 打开 Settings → Pages。
4. 在 Build and deployment 中选择 Deploy from a branch。
5. 选择 main 分支和 /(root)，保存。
6. 在 Pages 设置中查看发布地址与构建状态。

教程使用 GitHub Pages 内置 Jekyll Markdown 渲染。无需 npm、数据库、Stripe 或自定义 Actions。仓库需具备 Pages 发布权限。请勿上传原项目真实 .env 文件。

本教程未实际部署。GitHub UI 与主题支持情况未联网核验。所有章节也可直接在 GitHub 仓库中阅读。
