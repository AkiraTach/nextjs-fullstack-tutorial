Next.js 全栈最佳实践教程

用两个完整的 Next.js 电商项目学全栈开发：它们实现同一个网店，却走了不同的技术路线——一个用 Drizzle ORM + JWT + Stripe，一个用手写 SQL + 数据库会话 + 订单状态机。对照着读，你学到的不是 API，而是每个决策背后的取舍。

从导读开始：先把两个项目用 Docker 跑起来，各走一遍购物流程，再按章读代码。每章都有关键代码节选、两套实现对照、常见误区和动手练习。
